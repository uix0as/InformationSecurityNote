# 하이브리드 암호 시스템

하이브리드 암호 시스템은 대칭키 암호와 공개키 방식을 함께 사용하는 구조이다. 실제 웹 통신처럼 많은 데이터를 빠르게 보호해야 하는 환경에서 자주 사용한다.

## 기본 아이디어

- 데이터 본문은 빠른 대칭키로 암호화한다.
- 대칭키 자체는 공개키 방식이나 키 교환 방식으로 안전하게 공유한다.
- 이후 통신에서는 공유된 세션 키를 사용한다.

```mermaid
flowchart LR
    A["Client"] --> B["키 교환 또는 세션 키 보호"]
    B --> C["공유된 세션 키 생성"]
    C --> D["대칭키로 데이터 암호화"]
    D --> E["암호문 전송"]
    E --> F["세션 키로 복호화"]
```

## 왜 함께 쓰는가

공개키 암호는 키 배포 문제를 해결하는 데 유리하지만 느리다. 대칭키 암호는 빠르지만 처음에 키를 안전하게 공유해야 한다. 하이브리드 방식은 두 방식의 장점을 섞어 사용한다.

실제 웹 통신에서 이 개념은 [TLS/HTTPS](../web-security/tls-https.md)와 연결된다.
