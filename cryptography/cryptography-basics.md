# 암호학 기초 용어

암호학은 정보를 안전하게 보호하고 검증하기 위한 기술을 다룬다. 이 문서는 암호학 관련 문서를 읽기 전에 필요한 기본 용어를 정리한다.

| 용어 | 의미 |
| --- | --- |
| 평문 | 암호화되기 전의 원본 데이터 |
| 암호문 | 암호화된 데이터 |
| 암호화 | 평문을 암호문으로 바꾸는 과정 |
| 복호화 | 암호문을 다시 평문으로 바꾸는 과정 |
| 암호 해독 | 키 없이 암호를 깨거나 알고리즘/구현을 분석하는 시도 |
| 키 | 암호화, 복호화, 서명, 검증 등에 사용되는 값 |
| 암호시스템 | 알고리즘, 키, 운영 방식이 합쳐진 전체 구조 |

## 암호화, 인코딩, 해시의 차이

| 구분 | 되돌릴 수 있는가 | 목적 |
| --- | --- | --- |
| 암호화 | 키가 있으면 복호화 가능 | 기밀성 보호 |
| 인코딩 | 규칙만 알면 복원 가능 | 표현 형식 변환 |
| 해시 | 원래 값으로 복원 불가 | 무결성 검증, 식별값 생성 |

예를 들어 Base64는 인코딩이지 암호화가 아니다. 누구나 규칙을 알면 원래 값을 복원할 수 있기 때문이다. 반면 암호화는 키 없이는 원래 값을 알기 어렵게 만드는 것이 목적이다.

## 양방향과 단방향

- 대칭키 암호와 공개키 암호는 복호화가 가능하므로 양방향 방식이다.
- 해시는 원래 값을 복원하는 것이 목적이 아니므로 단방향 방식이다.
