# 해시 함수와 무결성 검증

해시 함수는 임의 길이의 입력을 고정 길이의 값으로 바꾸는 함수이다. 보안 분야에서는 파일이나 메시지가 바뀌었는지 확인하는 무결성 검증에 많이 사용한다.

## 암호학적 해시의 특징

| 특징 | 의미 |
| --- | --- |
| 단방향성 | 해시값만 보고 원래 입력을 알아내기 어렵다. |
| 충돌 저항성 | 서로 다른 두 입력이 같은 해시값을 갖게 만들기 어렵다. |
| 작은 변화에 큰 결과 변화 | 입력이 조금만 바뀌어도 해시값이 크게 달라진다. |

## 알고리즘 예시

| 알고리즘 | 상태 |
| --- | --- |
| MD5 | 충돌 취약점 때문에 보안 용도로 비권장 |
| SHA-1 | 충돌 취약점 때문에 보안 용도로 비권장 |
| SHA-2 | SHA-256, SHA-384, SHA-512 등이 널리 사용됨 |
| SHA-3 | SHA-2와 다른 구조의 비교적 최신 계열 |

## 보안용 해시와 오류 검출용 값

| 구분 | 예시 | 용도 | 보안 관점 |
| --- | --- | --- | --- |
| 암호학적 해시 | SHA-256, SHA-512 | 무결성 검증, 전자서명 입력 | 공격자를 고려한 충돌 저항성이 중요 |
| 오류 검출용 값 | CRC, Checksum, FCS | 전송 중 오류 검출 | 의도적 변조 방어에는 부족할 수 있음 |

Ethernet의 FCS는 프레임 오류를 검출하기 위한 값이다. 공격자가 의도적으로 데이터를 조작하는 상황까지 막기 위한 전자서명이나 메시지 인증 코드와는 목적이 다르다.
