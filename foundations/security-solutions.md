# 보안 솔루션 기본 구조

보안 솔루션은 네트워크와 시스템을 보호하기 위해 트래픽을 허용하거나 차단하고, 침입 징후를 탐지하며, 웹 요청이나 악성코드 같은 특정 위협을 줄이는 역할을 한다.

```text
Internet -> Firewall/WAF/IPS -> Internal Network
```

## 주요 솔루션

| 솔루션 | 주요 역할 | 특징 |
| --- | --- | --- |
| Firewall | 정책 기반 허용/차단 | IP, 포트, 프로토콜 기준으로 접근을 제어한다. |
| IDS | 침입 탐지 | 이상 징후를 탐지하고 알림이나 로그를 남긴다. |
| IPS | 침입 방지 | 인라인으로 배치되어 탐지한 트래픽을 차단할 수 있다. |
| UTM | 통합 위협 관리 | 방화벽, IPS, VPN, 안티바이러스 등 여러 기능을 하나로 묶는다. |
| WAF | 웹 방화벽 | HTTP/HTTPS 요청 내용을 보고 웹 공격 시도를 탐지하거나 차단한다. |

## 탐지와 차단

IDS와 IPS의 가장 큰 차이는 조치 방식이다.

- IDS는 트래픽을 관찰하고 의심스러운 이벤트를 기록한다.
- IPS는 트래픽 경로 중간에 위치해 의심스러운 패킷을 차단할 수 있다.

IDS는 미러링 포트나 TAP 장비를 통해 트래픽을 복사해서 보는 경우가 많고, IPS는 보통 인라인 구조로 배치된다. 인라인 장비는 차단이 가능하지만 장애가 나면 통신 경로에 영향을 줄 수 있다.

## WAF의 위치

WAF는 일반 방화벽보다 웹 계층에 가까운 요청을 본다. 예를 들어 방화벽은 `TCP 443` 접속 여부를 판단하지만, WAF는 HTTP 메서드, URL, 헤더, 파라미터, 쿠키 같은 웹 요청의 내용을 검사할 수 있다.
