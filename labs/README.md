# 실습 메모 모음

이 폴더는 정보보안과 네트워크 기초를 공부하면서 수행한 실습 메모를 정리한다.

실습은 개인 학습 환경이나 명시적으로 허가된 환경에서만 수행한다. 실제 IP, 계정명, 내부망 정보, 스크린샷의 개인정보는 GitHub에 올리기 전에 가려야 한다.

## 실습 문서

- [Rocky Linux 네트워크 명령어 실습](./rocky-linux-network-practice.md)

## 기록 형식

실습 문서는 다음 형식으로 정리한다.

- 목적: 무엇을 확인하려는 실습인지
- 명령어: 사용한 명령어
- 관찰 결과: 출력에서 확인한 내용
- 해석: 결과가 의미하는 것
- 주의할 점: 헷갈렸던 부분이나 보안 주의사항
